# Fita Novas · Demo de web y CRM

Propuesta de Agallart Digital. No es una web oficial de Fita Novas.

Prueba la solicitud de una clase desde la web; abre el panel, confirma la plaza o la espera y consulta la ficha del alumno. El calendario permite ver participantes y marcar asistencia de una sesión.

Disciplinas de referencia: ballet, contemporáneo y jazz, visibles en el perfil público de la escuela. Todos los grupos, edades, alumnos, aforos, horarios y eventos de la demo son ficticios. Los cambios solo viven en memoria y se reinician al recargar. No realiza reservas, no envía comunicaciones y no debe recibir datos reales.

La versión final requerirá autenticación, almacenamiento y configuración de formularios. Precio y alcance comercial pendientes de acordar.
